לטייל עם חנה — הפעלה מקומית ב-Windows — LIVE CONNECTED
=======================================================

החבילה כבר מכילה ב-js/supabase-config.js את Project URL + Publishable Key הציבורי של:
Chana Tours / rxapuzqnatmcapgacpfb.

א. בדיקה
--------
1. חלץ את ה-ZIP.
2. פתח PowerShell בתוך תיקיית הפרויקט.
3. הרץ:

   npm run check
   py -m http.server 5500

4. פתח:
   http://localhost:5500
   http://localhost:5500/admin.html

ב. הגדרה מחדש של Publishable Key, רק אם ה-key הוחלף בעתיד
-------------------------------------------------------
   $env:SUPABASE_URL="https://rxapuzqnatmcapgacpfb.supabase.co"
   $env:SUPABASE_PUBLISHABLE_KEY="sb_publishable_..."
   node scripts/configure-supabase.mjs
   npm run check

אין להשתמש ב-service_role, Secret Key או בסיסמת DB בדפדפן.

ג. Admin
--------
משתמש ה-Auth של חנה ורשומת admin_profiles הפעילה כבר קיימים ב-LIVE. מתחברים עם האימייל והסיסמה שנקבעו ב-Supabase Auth.
ראה supabase/ADMIN_SETUP.sql.

ד. עצירת השרת
-------------
Ctrl + C
